# หน้า Dashboard ดูยอดขาย

**วันที่:** 2026-08-02
**สถานะ:** ร่าง (Draft)

## ที่มา / บริบท

เจ้าของร้าน/แอดมินต้องการหน้า dashboard สำหรับดูภาพรวมยอดขายของร้านกาแฟ เพื่อให้ทราบสถานการณ์การขายในแต่ละช่วงเวลาโดยไม่ต้องไปไล่ดูข้อมูลออเดอร์ทีละรายการ requirement นี้เป็นฟีเจอร์ analytics ที่ต่อยอดจากระบบสั่งอาหาร/ออเดอร์หลัก (ดู [[20260802-001-table-qr-ordering|ระบบสั่งกาแฟจากโต๊ะด้วยการสแกน QR Code]]) โดยในเวอร์ชันนี้เน้นเฉพาะยอดขายรวมพื้นฐานก่อน ส่วนฟีเจอร์ analytics ขั้นสูงจะพิจารณาต่อยอดในอนาคต

## ความต้องการ (Requirement)

ต้องมีหน้า dashboard ที่แสดง "ยอดขายรวมพื้นฐาน" ของร้าน ได้แก่ยอดขายรวม (จำนวนเงิน) และจำนวนออเดอร์ โดยผู้ใช้สามารถเลือกดูข้อมูลตามช่วงเวลาที่กำหนดไว้ล่วงหน้า (preset) ได้แก่ "วันนี้", "สัปดาห์นี้" และ "เดือนนี้" หน้านี้จำกัดสิทธิ์การเข้าถึงเฉพาะเจ้าของร้าน/แอดมินเท่านั้น พนักงานทั่วไป (พนักงานเสิร์ฟ, บาริสต้า) ไม่สามารถเข้าถึงได้

## ขอบเขต (Scope)

### สิ่งที่ต้องทำ (In scope)
- หน้า dashboard แสดงยอดขายรวม (จำนวนเงิน) ตามช่วงเวลาที่เลือก
- หน้า dashboard แสดงจำนวนออเดอร์ตามช่วงเวลาที่เลือก
- ตัวเลือกช่วงเวลาแบบ preset สำเร็จรูป: "วันนี้", "สัปดาห์นี้", "เดือนนี้"
- การจำกัดสิทธิ์เข้าถึงหน้านี้เฉพาะบทบาทเจ้าของร้าน/แอดมิน

### สิ่งที่ไม่ทำ (Out of scope)
- สินค้าขายดี (best seller ranking)
- การเปรียบเทียบยอดขายระหว่างช่วงเวลา (period comparison)
- กราฟแนวโน้มยอดขายละเอียด (detailed trend chart)
- การ export รายงาน (เช่น CSV/PDF)
- Custom date range picker (เลือกช่วงวันที่เอง)

## กฎทางธุรกิจ / เงื่อนไข (Business Rules)
- เฉพาะผู้ใช้ที่มีบทบาทเจ้าของร้าน/แอดมินเท่านั้นที่เข้าถึงหน้า dashboard นี้ได้ บทบาทอื่น (พนักงานเสิร์ฟ, บาริสต้า) ไม่มีสิทธิ์เข้าถึง
- ช่วงเวลาที่แสดงผลจำกัดเฉพาะ preset ที่กำหนดไว้ล่วงหน้าเท่านั้น ("วันนี้", "สัปดาห์นี้", "เดือนนี้") ไม่มีการเลือกช่วงวันที่แบบกำหนดเอง
- ข้อมูลที่แสดงในเวอร์ชันนี้จำกัดเฉพาะยอดขายรวมและจำนวนออเดอร์ ไม่รวมมิติการวิเคราะห์อื่นใด

## หมายเหตุ

- ความสำคัญ/ลำดับก่อนหลัง: กำหนดเป็น Medium priority เนื่องจากเป็นฟีเจอร์ analytics ที่ต่อยอดจากระบบสั่งอาหาร/ออเดอร์หลัก มีประโยชน์แต่ไม่ใช่ core flow ที่บล็อกการใช้งานร้าน
- ฟีเจอร์ขั้นสูง เช่น สินค้าขายดี, การเปรียบเทียบช่วงเวลา, กราฟแนวโน้มละเอียด, การ export รายงาน และ custom date range picker ถูกตัดออกจากขอบเขตนี้อย่างชัดเจน แต่เก็บไว้เป็นแนวทางสำหรับต่อยอดในอนาคต
- ผลการตรวจสอบเอกสารเดิม: grep คำว่า "ยอดขาย", "dashboard", "รายงาน" ในโฟลเดอร์ `01-spec/` แล้วไม่พบเอกสารเดิมที่เกี่ยวข้องหรือทับซ้อน (มีเพียง 20260802-001-table-qr-ordering.md ซึ่งเป็นเรื่อง QR ordering คนละเรื่อง) จึงสร้างเป็นเอกสารใหม่แยกต่างหาก
