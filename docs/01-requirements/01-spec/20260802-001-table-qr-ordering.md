# ระบบสั่งกาแฟจากโต๊ะด้วยการสแกน QR Code

**วันที่:** 2026-08-02
**สถานะ:** ร่าง (Draft)

## ที่มา / บริบท

เจ้าของร้านกาแฟต้องการให้ลูกค้าสามารถสั่งกาแฟได้เองจากโต๊ะ โดยไม่ต้องเดินไปสั่งที่เคาน์เตอร์ เพื่อลดภาระพนักงานและลดเวลารอคิว ลูกค้าจะเข้าถึงระบบผ่านการสแกน QR code ที่ติดอยู่บนโต๊ะแต่ละโต๊ะ ซึ่งจะเปิดเป็นหน้าเว็บสั่งอาหารได้ทันทีโดยไม่ต้องติดตั้งแอปพลิเคชันใด ๆ

## ความต้องการ (Requirement)

ลูกค้านั่งที่โต๊ะ สแกน QR code ประจำโต๊ะนั้น เพื่อเปิดหน้าเว็บสั่งอาหาร/เครื่องดื่ม เลือกเมนูพร้อมปรับตัวเลือกเสริมตามต้องการ แล้วกดยืนยันสั่ง ออเดอร์จะเข้าคิวของบาริสต้า/คนชงกาแฟโดยตรงทันที เมื่อบาริสต้าทำเสร็จและกดยืนยันว่าเสร็จ ระบบจะแจ้งเตือนพนักงานเสิร์ฟโดยอัตโนมัติให้นำไปเสิร์ฟที่โต๊ะนั้น ตลอดกระบวนการ ลูกค้าต้องเห็นสถานะออเดอร์ของตัวเองแบบ real-time บนหน้าจอที่ใช้สั่ง

ระบบมีผู้ใช้งาน 4 บทบาท:

1. **ลูกค้า** — สแกน QR, สั่งเมนู, ปรับตัวเลือกเสริม, ติดตามสถานะออเดอร์ real-time
2. **พนักงานเสิร์ฟ** — รับการแจ้งเตือนอัตโนมัติเมื่อออเดอร์ทำเสร็จ แล้วนำไปเสิร์ฟที่โต๊ะ
3. **บาริสต้า/คนชงกาแฟ** — เห็นคิวออเดอร์ที่เข้ามาโดยตรงจากลูกค้า ทำเครื่องดื่ม/อาหาร แล้วกดยืนยันว่าเสร็จ และสามารถปิดเมนูรายการที่หมดชั่วคราวได้
4. **ผู้จัดการร้าน** — จัดการเมนู รวมถึงปิด/เปิดเมนูรายการที่หมดชั่วคราวได้เช่นกัน

## ขอบเขต (Scope)

### สิ่งที่ต้องทำ (In scope)
- หน้าเว็บสั่งอาหาร/เครื่องดื่มที่เปิดได้ทันทีจากการสแกน QR code ประจำโต๊ะ โดยไม่ต้องติดตั้งแอป
- การเลือกเมนูพร้อมตัวเลือกเสริมครบทุกมิติ: ขนาด (S/M/L), ร้อน/เย็น, ระดับความหวาน, ชนิดนม, ท็อปปิ้ง/เพิ่มช็อต และช่องหมายเหตุพิเศษแบบ free text
- Flow ออเดอร์: ลูกค้ายืนยันสั่ง -> เข้าคิวบาริสต้าโดยตรงทันที (ไม่ผ่านพนักงานเสิร์ฟกดรับก่อน) -> บาริสต้ากดยืนยันเสร็จ -> แจ้งเตือนพนักงานเสิร์ฟอัตโนมัติ -> เสิร์ฟที่โต๊ะ
- การแสดงสถานะออเดอร์แบบ real-time ให้ลูกค้าเห็นบนหน้าจอที่ใช้สั่ง (เช่น "รับออเดอร์แล้ว" -> "กำลังทำ" -> "เสิร์ฟแล้ว")
- ฟีเจอร์ปิด/เปิดเมนูรายการชั่วคราว (manual toggle) โดยผู้จัดการร้านหรือบาริสต้า เมื่อสินค้าหมด

### สิ่งที่ไม่ทำ (Out of scope)
- ระบบชำระเงินออนไลน์ — ลูกค้ายังจ่ายเงินที่เคาน์เตอร์ตามปกติหลังสั่ง
- ระบบตัดสต็อกอัตโนมัติ
- ระบบจองโต๊ะ

## กฎทางธุรกิจ / เงื่อนไข (Business Rules)
- ออเดอร์ที่ลูกค้ายืนยันแล้วจะเข้าคิวของบาริสต้า/คนชงกาแฟโดยตรงทันที ไม่ต้องผ่านพนักงานเสิร์ฟกดรับก่อน
- เมื่อบาริสต้ากดยืนยันว่าออเดอร์ทำเสร็จ ระบบต้องแจ้งเตือนพนักงานเสิร์ฟโดยอัตโนมัติทันที
- ลูกค้าต้องเห็นสถานะออเดอร์ของตัวเองแบบ real-time ตลอดเวลาบนหน้าจอที่ใช้สั่ง
- ผู้จัดการร้านและบาริสต้ามีสิทธิ์กดปิดเมนูรายการใดรายการหนึ่งเป็นการชั่วคราวได้เองเมื่อสินค้าหมด (manual toggle) โดยไม่มีการตัดสต็อกอัตโนมัติในเฟสนี้
- เมื่อเมนูรายการใดถูกปิดชั่วคราว ต้องซ่อนหรือแสดงสถานะ "หมด" ให้ลูกค้าเห็นทันทีที่หน้าสั่งอาหาร
- การชำระเงินยังคงทำที่เคาน์เตอร์ตามปกติ ไม่มีการชำระเงินผ่านระบบนี้ในเฟสนี้
