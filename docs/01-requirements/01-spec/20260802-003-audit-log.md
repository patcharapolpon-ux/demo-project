# ระบบบันทึก Log (Audit Trail)

**วันที่:** 2026-08-02
**สถานะ:** ร่าง (Draft)

## ที่มา / บริบท

ต่อยอดจากระบบสั่งกาแฟจากโต๊ะด้วยการสแกน QR Code (ดู [[20260802-001-table-qr-ordering|ระบบสั่งกาแฟจากโต๊ะด้วยการสแกน QR Code]]) และหน้า Dashboard ดูยอดขาย (ดู [[20260802-002-sales-dashboard|หน้า Dashboard ดูยอดขาย]]) ที่มีอยู่แล้ว ร้านต้องการเก็บบันทึกการทำงาน (log) ของพนักงานในระบบ เพื่อให้สามารถตรวจสอบย้อนหลังได้กรณีเกิดปัญหาหรือข้อพิพาท (เช่น ออเดอร์ผิดพลาด, เมนูถูกปิดโดยไม่ทราบสาเหตุ) และเพื่อความปลอดภัยของข้อมูลในภาพรวม

## ความต้องการ (Requirement)

ระบบต้องบันทึก log เหตุการณ์สำคัญที่เกิดขึ้นในระบบ โดยแต่ละ log record ต้องระบุเวลาที่เกิดเหตุการณ์ (timestamp), ผู้ทำรายการ (user/role), ประเภทเหตุการณ์ และรายละเอียดที่เกี่ยวข้องกับเหตุการณ์นั้น log ที่เก็บไว้จะถูกลบออกจากระบบโดยอัตโนมัติเมื่อมีอายุเกิน 90 วัน และเฉพาะบทบาทผู้จัดการร้าน/แอดมินเท่านั้นที่มีสิทธิ์เข้าถึงหน้าดู log ย้อนหลัง บทบาทอื่น (พนักงานเสิร์ฟ, บาริสต้า) ไม่มีสิทธิ์เข้าถึง

## ขอบเขต (Scope)

### สิ่งที่ต้องทำ (In scope)
- บันทึก log เหตุการณ์สร้างออเดอร์ใหม่
- บันทึก log การเปลี่ยนสถานะออเดอร์ทุกครั้ง (รับออเดอร์ -> กำลังทำ -> เสร็จ -> เสิร์ฟแล้ว) พร้อม timestamp และผู้ทำรายการ (บาริสต้า/พนักงานเสิร์ฟคนไหน)
- บันทึก log การเปิด/ปิดเมนูรายการชั่วคราว พร้อม timestamp และผู้ทำรายการ (บาริสต้าหรือผู้จัดการร้าน)
- บันทึก log การเข้าถึงหน้า sales dashboard ว่าใคร (เจ้าของร้าน/แอดมิน) เข้าดูเมื่อไหร่
- นโยบายเก็บรักษา log: เก็บไว้ 90 วัน แล้วลบทิ้งอัตโนมัติ
- หน้าดู log ย้อนหลัง จำกัดสิทธิ์เฉพาะบทบาทผู้จัดการร้าน/แอดมิน

### สิ่งที่ไม่ทำ (Out of scope)
- การ export log เป็นไฟล์ (เช่น CSV) ในเฟสนี้
- ระบบแจ้งเตือน/alert อัตโนมัติจาก log (เช่น anomaly detection)
- log ระดับ infrastructure/server (เช่น server access log, network log) — ครอบคลุมเฉพาะ application-level business event log เท่านั้น

## กฎทางธุรกิจ / เงื่อนไข (Business Rules)
- ทุก log record ต้องมี timestamp, ผู้ทำรายการ (user/role), ประเภทเหตุการณ์ และรายละเอียดที่เกี่ยวข้อง (เช่น order id, เมนูที่ถูกปิด)
- Log ที่มีอายุเกิน 90 วันต้องถูกลบออกจากระบบโดยอัตโนมัติ (ตามหลัก data minimization)
- เฉพาะบทบาทผู้จัดการร้าน/แอดมินเท่านั้นที่เข้าถึงหน้าดู log ย้อนหลังได้ บทบาทอื่น (พนักงานเสิร์ฟ, บาริสต้า) ไม่มีสิทธิ์เข้าถึง
