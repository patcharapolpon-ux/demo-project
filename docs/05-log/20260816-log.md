## อัปเดต Prototype v1 ให้เป็น Interactive Prototype

- อัปเดต [[../02-design/01-prototypes/mockups/v1/index|Prototype v1]] (4 หน้าจอ) ให้เชื่อมโยงกันจริงผ่าน vanilla JS + localStorage (ไม่มี backend จริง เพราะเป็นไฟล์ static): `001-menu.html`, `001-product-detail.html`, `001-cart.html`, `001-order-status.html`
- ครอบคลุม requirement: 20260802-001 (ฝั่งลูกค้า)
- Interactivity หลัก: กดการ์ดเมนู -> navigate ไปหน้าปรับตัวเลือกพร้อม slug ผ่าน query string, คำนวณราคารวมสดตามตัวเลือก/จำนวน, เพิ่มลงตะกร้าจริงพร้อม toast, หน้าตะกร้าโหลด/ลบรายการจริงจาก localStorage และมี empty state, ยืนยันสั่งแล้วตั้งสถานะเริ่มต้นและ navigate ไปหน้าสถานะออเดอร์ที่อ่านสถานะจริงและมีปุ่ม "จำลองขั้นถัดไป" เลื่อนสถานะทดสอบ
- ไม่ได้สร้าง `DESIGN.md` ใหม่ในรอบนี้ — คงค่า design token เดิมทั้งหมดจาก [[../02-design/01-prototypes/DESIGN|DESIGN.md]] ที่มีอยู่แล้ว เพิ่มเฉพาะ behavior/JS

## เพิ่มไฟล์ Standalone ให้ Prototype v1

- เพิ่ม [[../02-design/01-prototypes/mockups/v1/index|Prototype v1]] ไฟล์ `001-standalone.html` ที่รวม 4 หน้าจอเดิม (`001-menu.html`, `001-product-detail.html`, `001-cart.html`, `001-order-status.html`) เข้าเป็นไฟล์เดียว
- ครอบคลุม requirement: 20260802-001 (ฝั่งลูกค้า) — ไม่มีการเปลี่ยนแปลงขอบเขตหน้าจอ แค่เปลี่ยนกลไก cross-file navigation + localStorage เป็น in-page section switching (`showScreen(slug)`) + state ในหน่วยความจำ JS ล้วน เพื่อให้เปิดทดสอบตรงผ่าน `file://` (double-click) ได้ทันทีโดยไม่ต้องตั้ง local web server
- แก้บั๊กที่พบระหว่างทดสอบชุดไฟล์แยกไปในตัว: checkbox "เพิ่มช็อตเอสเพรสโซ" ในหน้าปรับตัวเลือกเมนู เคย default checked ผิดพลาด ทำให้ราคารวมเริ่มต้นไม่ตรงกับราคาฐานของเมนู — ไฟล์ `001-standalone.html` แก้ให้เริ่มต้นไม่ติ๊กแล้ว (ไม่ได้ย้อนไปแก้ 4 ไฟล์แยกเดิม)
- อ้างอิง [[../02-design/01-prototypes/DESIGN|DESIGN.md]] ที่มีอยู่แล้ว (ไม่ได้สร้าง/แก้ไขในรอบนี้)
